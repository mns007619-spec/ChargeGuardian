# حارس الشحن — Charge Guardian

مشروع Android أولي بتصميم عربي RTL عصري، وحدّ الحماية الافتراضي 90٪.

## السلوك المقصود
- عند تشغيل الحماية، يراقب التطبيق توصيل الشاحن ونسبة البطارية.
- إذا وصل الهاتف إلى 90٪ أثناء بقاء الشاحن متصلًا، يعتبر فصل الشاحن بعد ذلك طبيعيًا.
- إذا فُصل الشاحن قبل بلوغ 90٪، يصدر إنذارًا متكررًا حتى إعادة توصيله.
- يحتاج التشغيل المستمر إلى إشعار دائم وإعفاء التطبيق من تقييد البطارية في بعض أجهزة Honor.

## البناء
1. افتح المجلد في Android Studio حديث.
2. اسمح بمزامنة Gradle وتنزيل إضافات Android عند توفر الإنترنت.
3. من قائمة Build اختر Build APK(s).
4. اختبره على الهاتف قبل الاعتماد عليه.

## ملاحظات مهمة
هذه نسخة مصدر أولية وليست ملف APK مُجمّعًا. يجب اختبار سلوك البثوث الخلفية والصوت على Honor X7c وإصدار Android المثبت عليه؛ قد تفرض بعض إصدارات Android/Honor قيودًا على الخدمات الخلفية أو مستوى الصوت. لا يمكن للتطبيق ضمان استمرار الإنذار إذا أُجبر على الإيقاف أو كُتم الصوت من النظام.

## إنشاء ملف APK دون تثبيت أدوات البرمجة على الهاتف

أُضيف مسار بناء تلقائي عبر GitHub Actions. لا يمكن إنشاء APK من هذا الملف المضغوط وحده على الهاتف؛ يلزم رفع المشروع إلى مستودع GitHub وتشغيل عملية البناء.

1. أنشئ مستودعًا جديدًا على GitHub باسم `ChargeGuardian` واجعله خاصًا إن رغبت.
2. ارفع محتويات مجلد `ChargeGuardian` إلى المستودع (بما فيها مجلد `.github`).
3. افتح تبويب **Actions**، ثم **Build Charge Guardian APK**، ثم **Run workflow**.
4. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل ونزّل ملف **ChargeGuardian-debug-apk** من قسم Artifacts.
5. فك ضغط الملف على الهاتف وافتح `app-debug.apk` للتثبيت. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

هذه نسخة Debug للاختبار وليست إصدارًا منشورًا. اختبر الإنذار فعليًا على Honor X7c قبل الاعتماد عليه؛ وقد يلزم السماح بالإشعارات وتعطيل تحسين البطارية للتطبيق.
